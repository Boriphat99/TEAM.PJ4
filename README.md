# เชื่อมระบบหอพัก T&T Mansion กับ Supabase (PostgreSQL)

ไฟล์ในโฟลเดอร์นี้
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `01_schema.sql` | สร้างตารางทั้งหมดตาม ER Diagram + สิทธิ์/RLS + ที่เก็บไฟล์ + Realtime + ข้อมูลเริ่มต้น (ห้อง 27 ห้อง) |
| `02_staff_emails.sql` | กำหนดอีเมล **ผู้ดูแลระบบ** และ **เจ้าของกิจการ** |
| `05_period_lock.sql` | ล็อกรอบบิลหลังวันที่ 10 ของเดือนถัดไป (และลบตัวกรองอีเมลเดิมถ้าเคยรัน) |
| `create-tenant/index.ts` | Edge Function ให้ผู้ดูแลสร้างบัญชีผู้เช่า (ผู้เช่าสมัครเองไม่ได้) |
| `functions/send-email/index.ts` | Edge Function ส่งอีเมลใบแจ้งหนี้/ใบเสร็จอัตโนมัติ (ผ่าน Resend) |
| `index.html` | โครงหน้าเว็บ (HTML) เชื่อมกับ `style.css` และ `script.js` |
| `style.css` | สไตล์/หน้าตาของหน้าเว็บทั้งหมด (CSS) |
| `script.js` | โค้ดการทำงานทั้งหมด รวมส่วนเชื่อม Supabase (JavaScript) |
| `07_edit_rules.sql` | กฎแก้ไข: ผู้เช่าส่งสลิปใหม่ได้ก่อนยืนยัน, ผู้ดูแลแก้บิลได้เมื่อยังไม่ชำระ, ล็อกเลขมิเตอร์ก่อนหน้า |

## ขั้นตอน

1. **สร้างโปรเจกต์** ที่ supabase.com
2. **SQL Editor** → วางทั้งไฟล์ `01_schema.sql` → Run (รันซ้ำได้)
3. แก้อีเมลใน `02_staff_emails.sql` เป็นอีเมลจริงของผู้ดูแลและเจ้าของ → Run
4. **ปิดการสมัครสมาชิกสาธารณะ**: Authentication → Sign In / Providers → ปิด *Allow new users to sign up* (ชื่อเมนูอาจต่างตามเวอร์ชัน) เพราะผู้เช่าทุกคนสร้างโดยผู้ดูแลผ่านฟังก์ชัน `create-tenant` และบัญชีผู้ดูแล/เจ้าของสร้างใน Dashboard
   **Authentication → URL Configuration**: ตั้ง *Site URL* เป็นที่อยู่เว็บจริง และเพิ่มใน *Redirect URLs* (ใช้กับลิงก์ยืนยันอีเมล/รีเซ็ตรหัสผ่าน)
   อีเมลยืนยันของ Supabase มีโควตาจำกัด แนะนำตั้ง *SMTP* ของตัวเอง (เช่น Resend) ที่ Authentication → SMTP Settings
5. **Edge Function ส่งอีเมลอัตโนมัติ** (ต้องติดตั้ง Supabase CLI)
   ```bash
   supabase link --project-ref <PROJECT_REF>
   supabase secrets set RESEND_API_KEY=re_xxxxxxxx MAIL_FROM="T&T Mansion <billing@โดเมนของคุณ>"
   supabase functions deploy send-email
   ```
   (ยังไม่ตั้ง `RESEND_API_KEY` ได้ ระบบจะเก็บอีเมลไว้ในคิวสถานะ "wait" แล้วส่งให้ทีหลังเมื่อตั้งค่าเสร็จ กดส่งซ้ำได้ที่หน้ารายงาน)
6. **ใส่ค่าเชื่อมต่อในไฟล์ `script.js`** ที่บรรทัด `const SB_CFG = ...` (ใกล้ต้นไฟล์) หรือเพิ่มแท็กสคริปต์ใน `index.html` ก่อน `<script src="script.js">`:
   `window.TTM_SB = { url: 'https://<PROJECT_REF>.supabase.co', key: '<anon public key>' }`
   (Project Settings → API → *Project URL* และ *anon public* — ห้ามใช้ service_role key ในหน้าเว็บ)
   ติดตั้งฟังก์ชันสร้างผู้เช่า: `supabase functions deploy create-tenant` (ใช้ค่า SUPABASE_URL / SERVICE_ROLE_KEY ที่ Supabase ให้อยู่แล้ว ไม่ต้องตั้ง secret เพิ่ม)
7. **นำไฟล์ `index.html`, `style.css`, `script.js` ขึ้นโฮสต์พร้อมกัน (วางในโฟลเดอร์เดียวกัน)** เช่น Netlify / Vercel / Cloudflare Pages / GitHub Pages (ต้องเป็น https)
   > หน้าที่เผยแพร่ผ่าน claude.ai เชื่อมต่อ Supabase ไม่ได้ เพราะหน้านั้นถูกบล็อกการเรียกเว็บภายนอก ลิงก์นั้นจึงเป็นโหมดทดลอง (เก็บข้อมูลในเบราว์เซอร์)
8. **สร้างบัญชีผู้ดูแลและเจ้าของ** ที่ Supabase Dashboard → Authentication → Users → Add user → Create new user (ติ๊ก *Auto Confirm User*) ด้วยอีเมลที่กำหนดไว้ในข้อ 3 → ระบบกำหนดบทบาทให้อัตโนมัติ
   **สร้างบัญชีผู้เช่า**: ผู้ดูแลล็อกอินเว็บ → เลือกห้องว่าง → "เพิ่มผู้เช่า" (กรอกชื่อ เบอร์ อีเมล รหัสผ่าน) → ระบบสร้างบัญชีและจัดห้องให้ แล้วคัดลอกข้อความอีเมล/รหัสผ่านไว้ให้ส่งต่อผู้เช่า (ผู้เช่าเปลี่ยนรหัสผ่านเองได้ในหน้าโปรไฟล์)

## สิทธิ์การเข้าถึง (Row Level Security)
- **ผู้ดูแลระบบ**: จัดการได้ทุกอย่าง รับคำขอช่วยเหลือและตอบกลับ (ส่งคำขอเองไม่ได้)
- **เจ้าของกิจการ**: ดูห้อง สัญญา บิล รายงานได้อย่างเดียว ส่งคำขอช่วยเหลือได้
- **ผู้เช่า**: เห็นเฉพาะห้อง สัญญา บิล สลิป และคำขอของตัวเอง แก้ตารางเงินตรงๆ ไม่ได้ แจ้งชำระผ่านฟังก์ชัน `submit_payment` (เซิร์ฟเวอร์คำนวณค่าปรับให้)

## ลำดับการทำงานอัตโนมัติ
ผู้ดูแลออกใบแจ้งหนี้ → ฐานข้อมูลสร้างรายการในคิวอีเมลเอง → เว็บสั่ง Edge Function ส่งอีเมลถึงผู้เช่า
ผู้ดูแลอนุมัติการชำระ → ฐานข้อมูลสร้างอีเมลใบเสร็จ → ส่งอัตโนมัติ
(ตั้ง `pg_cron` ในท้ายไฟล์ `01_schema.sql` เพิ่มได้ถ้าอยากให้ส่งซ้ำอัตโนมัติ)

## ข้อควรรู้
- ผู้ดูแลตั้งรหัสผ่านให้ผู้เช่าได้เฉพาะตอนสร้างบัญชี หลังจากนั้นผู้เช่าเปลี่ยนเองในหน้าโปรไฟล์ หรือใช้ "ลืมรหัสผ่าน" (ลิงก์ทางอีเมล) และอีเมลที่ใช้ล็อกอินแก้ในโปรไฟล์ไม่ได้
- เบอร์โทรติดต่อในหน้าช่วยเหลือของผู้เช่า/เจ้าของ ดึงจากเบอร์ในโปรไฟล์ของผู้ดูแลและเจ้าของ ให้ทั้งสองคนกรอกเบอร์ในหน้าโปรไฟล์
- ถ้าอยากล้างข้อมูลทดลองก่อนใช้งานจริง: `truncate public.invoices, public.meter_readings, public.contracts restart identity cascade;`
