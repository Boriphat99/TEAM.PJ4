# แผนที่ไฟล์โค้ดเว็บแอป T&T Mansion (หลังแยกไฟล์)

แยกจาก `script.js` (1,625 บรรทัด) และ `style.css` (4,399 บรรทัด) ตอนแยกไฟล์ไม่ได้แก้โค้ด แล้วรอบนี้ปรับปรุงเพิ่มดังรายการ "สิ่งที่ปรับปรุงล่าสุด" ด้านล่าง ไฟล์อื่นนอกจากที่ระบุยังเหมือนเดิมทุกตัวอักษร

## กติกาสำคัญ
- **ลำดับการโหลดมีผล** ไฟล์ JS ต้องโหลดตามเลขหน้าชื่อไฟล์ ไฟล์ CSS ก็เช่นกัน (สไตล์ที่อยู่หลังจะทับสไตล์ก่อนหน้า) ห้ามสลับลำดับใน `index.html`
- ถ้าเพิ่มไฟล์ใหม่ ให้เพิ่มแท็ก `<script>` / `<link>` ใน `index.html` ตามลำดับที่ต้องการ
- ตอนอัปโหลดขึ้นโฮสต์ ต้องอัปโหลดทั้งโฟลเดอร์ `css/` และ `js/` พร้อม `index.html` (ไม่ต้องใช้ `script.js` และ `style.css` เดิมอีก)

## สิ่งที่ปรับปรุงล่าสุด
- **สลับธีมเนียน:** `applyTheme()` ใน `js/18_shell_render_v2_helpers.js` ใช้ View Transitions (ภาพเดิมค่อยๆ เลือนเป็นภาพธีมใหม่ทั้งหน้า) แทนการใส่ transition ความยาวต่างกันทีละองค์ประกอบ ถ้าเบราว์เซอร์ไม่รองรับจะใช้ transition เวลาเท่ากันทั้งหน้า และอัปเดตสีแถบเบราว์เซอร์บนมือถือ (`theme-color`) ตามธีม
- **การ์ด LINE (หน้าช่วยเหลือ):** แก้ markup ใน `js/17_help_news_contacts.js` ปุ่ม "เพิ่มเพื่อนใน LINE" เดิมมี `display:inline-block` ฝังอยู่ ทำให้ตัวหนังสืออยู่บนสุดของปุ่ม ตอนนี้ปุ่มทุกตัวจัดกึ่งกลาง และการ์ดเรียงใหม่ตามขนาดจอ
- **ฟอนต์:** ใช้ IBM Plex Sans Thai ตัวเดียวทั้งไทย/อังกฤษ/ตัวเลข (เดิมผสม Inter ทำให้ตัวอังกฤษใหญ่กว่าตัวไทย) เลิกเว้นตัวอักษรติดลบกับหัวข้อภาษาไทย และเลิกใช้น้ำหนัก 800 ที่ไม่มีในฟอนต์
- **รองรับ 3 อุปกรณ์:** มือถือ ≤800px (เมนูล่าง popup แบบแผ่นเลื่อนขึ้น), แท็บเล็ต 801–1099px (ตารางเป็นการ์ด 2 คอลัมน์), คอมพิวเตอร์ ≥1100px (ตารางย่อช่องไฟ ปุ่มขึ้นบรรทัดได้ จอใหญ่จัดกึ่งกลาง)
