# จดมิเตอร์ตอนย้ายเข้า/ย้ายออก + ไฟล์สัญญาแยกต่อสัญญา — เอกสารออกแบบ

วันที่ 17 พ.ย. 2569 · ที่มา: รายงานบั๊ก 17 พ.ย. ข้อ 2 และ 3 · ผู้ใช้เลือกแนวทางผ่านคำถามในแชท

## ปัญหา
1. บิลแรกของผู้เช่าใหม่นับหน่วยไฟจากเลขที่จดครั้งล่าสุดของห้อง → รวมไฟของคนเก่า/ช่วงห้องว่าง
2. ผู้เช่าที่ย้ายออกกลางรอบไม่ถูกเก็บค่าไฟช่วงสุดท้าย
3. ไฟล์สัญญา PDF เก็บห้องละไฟล์ (`101.pdf`) → สัญญาคนเก่าถูกเขียนทับ

## สิ่งที่ผู้ใช้เลือก
- จดเลขมิเตอร์ทั้งตอนย้ายเข้าและย้ายออก
- ตอนย้ายออก: ออกบิลสุดท้ายทันที **ค่าไฟอย่างเดียว** (ค่าเช่าเดือนสุดท้ายใช้ค่าเช่าล่วงหน้าในเงินแรกเข้า) ผู้เช่าจ่ายเงินสด/QR ได้เหมือนบิลปกติ
- ไฟล์สัญญาเก็บแยกต่อสัญญา

## การทำงาน
### ย้ายเข้า (ทุกเส้นทาง: เพิ่มผู้เช่าใหม่ / จัดผู้เช่าเข้าห้อง / ย้ายห้อง)
- ฟอร์มมีช่อง "เลขมิเตอร์ตอนย้ายเข้า" (บังคับ, ค่าเริ่มต้น = เลขล่าสุดของห้อง)
- เก็บที่ `contracts.start_meter`
- บิลเดือนแรกของสัญญา: เลขก่อนหน้า = `start_meter` (ถ้าสัญญาเริ่มหลังวันจดมิเตอร์ครั้งล่าสุดของห้อง)

### ย้ายออก (ทุกเส้นทาง: ปุ่มย้ายออก / เปลี่ยนสถานะห้องเป็นว่าง-ปิดปรับปรุง / แก้ข้อมูลผู้เช่าเป็น "ย้ายออกแล้ว" / ย้ายห้อง)
- หน้าต่างยืนยันมีช่อง "เลขมิเตอร์ตอนย้ายออก" (เว้นว่างได้ = ไม่ออกบิลสุดท้าย) แสดงหน่วยและยอดค่าไฟทันที
- เก็บที่ `contracts.end_meter`
- ถ้าหน่วย > 0 → ออกบิลสุดท้าย
  - `invoices.kind = 'final'`, รอบบิล = เดือนที่ย้ายออก (เวลาไทย)
  - รหัส `INVyyyymm-ห้อง-Fวันที่`, มีเฉพาะรายการค่าไฟ
  - `meter_from` / `meter_to` เก็บบนบิล (ไม่สร้างแถว meter_readings เพราะ 1 ห้องมีได้แถวเดียวต่อเดือน)
  - ครบกำหนดและค่าปรับตามกฎเดิม (วันที่ 5 ของเดือนถัดไป)
- ผู้เช่าที่ย้ายออกแล้วยังเข้าสู่ระบบได้ ถ้ามีบิลค้างชำระ (เพื่อจ่ายบิลสุดท้าย) — ถ้าไม่มีบิลค้าง ยังถูกปิดกั้นเหมือนเดิม
- "ย้ายกลับเข้าพัก" → ลบบิลสุดท้ายที่ยังไม่ชำระของคนนั้น

### ไฟล์สัญญา
- เก็บที่ Storage `contracts/<contract_id>.pdf` + `contracts.pdf_path/pdf_name/pdf_size`
- ผู้เช่าเปิดได้เฉพาะไฟล์ของสัญญาตัวเอง (ทั้งปัจจุบันและที่สิ้นสุดแล้ว) · แอดมิน/เจ้าของเปิดได้ทั้งหมด

## ฐานข้อมูล
- `contracts` + start_meter, end_meter, pdf_path, pdf_name, pdf_size
- `invoices` + kind ('monthly'|'final'), meter_from, meter_to
- unique (contract_id, billing_month) เหลือเฉพาะ kind = 'monthly'
- `guard_meter_chain`: เลขก่อนหน้าใช้ start_meter ของสัญญาปัจจุบันเมื่อสัญญาเริ่มหลังวันจดครั้งล่าสุด
- นโยบาย Storage `st_con_sel`: ตามสัญญาของตัวเอง
- Edge Function `create-tenant` รับ start_meter

## ไม่ทำ
- ไม่คิดค่าเช่าตามสัดส่วนวัน · ไม่ย้ายไฟล์ PDF เดิม (ยังไม่มีไฟล์ในระบบ) · ไม่ลบคอลัมน์ rooms.contract_pdf_* ในรอบนี้
