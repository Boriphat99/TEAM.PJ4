# T&T Mansion Payment System — โครงสร้างโปรเจกต์

```
TTM/
├─ src/                      ← โฟลเดอร์ที่แก้โค้ด (เปิดใน VS Code)
│  ├─ index.html             ← ลิสต์ไฟล์ CSS/JS เรียงตามลำดับโหลด (ลำดับมีผล!)

│  │  ├─ auth/               หน้าเข้าสู่ระบบ ช่องกรอก dialog

│  │  ├─ components/         ปุ่มสลับภาษา/ธีม · แอนิเมชัน

│  │  └─ polish/             ปรับดีไซน์เพิ่ม · ฟอนต์/ตัวอักษร
│  └─ js/
│     ├─ core/               โลโก้ ตัวแปรหลัก ตัวช่วยคำนวณ (ค่าปรับ สถานะบิล) สถานะ+popup
│     ├─ i18n/               พจนานุกรมไทย/อังกฤษ · ใช้ภาษา/ธีม
│     ├─ config/             ค่าเชื่อมต่อ Supabase  ← แก้ URL / anon key ที่นี่
│     ├─ data/               ข้อมูลตั้งต้น/โหมดทดลอง · เก็บในเบราว์เซอร์

│  └─ script.js
```

## ใช้งาน
| ทำอะไร | วิธี |
|---|---|
| ดู/แก้โค้ด | แก้ไฟล์ใน `src/` (เปิด `src/index.html` ด้วย Live Server เพื่อทดสอบได้เลย) |
| เตรียมขึ้นเว็บ | เปิด Terminal ในโฟลเดอร์ `TTM` แล้วรัน `npm run build` (หรือ `node build.js`) |
| ขึ้นเว็บ (GitHub Pages) | อัปโหลด **3 ไฟล์ใน `dist/`** ไปที่รากของ repo (ไม่ต้องอัปโหลดโฟลเดอร์ `src`) |

## กติกาสำคัญ
- **ลำดับไฟล์มีผล** ทั้ง JS (ไฟล์หลังใช้ตัวแปร/ฟังก์ชันของไฟล์ก่อน) และ CSS (ไฟล์หลังทับไฟล์ก่อน) จึงเก็บเลขนำหน้าชื่อไฟล์ไว้ ลำดับจริงดูที่ `src/index.html`
- **เพิ่มไฟล์ใหม่:** สร้างไฟล์ในโฟลเดอร์ที่เหมาะสม แล้วเพิ่มแท็ก `<link>` / `<script>` ใน `src/index.html` ตรงตำแหน่งที่ต้องการ
- **แก้แล้วต้อง build ใหม่ก่อนอัปโหลดทุกครั้ง** ไม่เช่นนั้นเว็บจะเป็นเวอร์ชันเก่า
- `build.js` ไม่ต้องติดตั้งแพ็กเกจเพิ่ม ใช้ Node.js อย่างเดียว

## ปรับปรุงล่าสุด (สรุป)
